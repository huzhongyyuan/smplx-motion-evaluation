# Frozen evaluation protocols

The authoritative description is [数据集评测说明.md](数据集评测说明.md).

- HumanML3D: author20fps/263D, sourceTEST4198, author epoch28 evaluators and normalization, batch32/drop_last, unit4 cropping, Diversity300,20 repetitions. GT reconstruction has no multimodality score. Generated motion requires a frozen caption/crop plan and genuine100x30 outputs.
- AIST++: explicitly adapted SMPL-X30 domain, official strictTRAIN952 reference, officialTEST20; TEST20+VAL20 reported separately. Native60fps uses exact `[::2]` sampling. Fixed24 points are body22 plus SMPL-X left/right middle1 palm anchors. Defaultshape/fingers, worldpelvis preserved; actual SMPL-X geometry is never converted back to SMPL for the main score. Time parameters are1/30, author feature equations/windows/thresholds and FID/diversity formulas unchanged. Not the original SMPL60 paper protocol.
- FineDance: the GT main row uses LODGE's published202-source/404-feature pool, verified by hash, scored with unchanged author normalization/metrics. PaperGT FID is unreported. Motion scoring uses original preprocessing, grounding, ROW6D, FK,1024frame cap and original feature constants against that same pool. The separate loader diagnostic has20 TEST IDs minus ignored120, giving19; `infer_lodge.py` still lists20 including120. Neither that diagnostic nor a new feature re-extraction replaces the published GT pool.
- BEAT2: the only current protocol is nativeSMPL-X30 body+hands, source-pinned EMAGE2024 BC/L1 caller and author legacy normalizer, speaker2TEST15, original L1 in-place mutation beforeBC, threshold0.3, whole-second/8frame/64+60k loader support. BC retains raw0–1 value; paper display israw×10. Approximate reproduction accepted; exact historical paper-environment identity is not asserted. This protocol has noFGD. The previous public2025/fullCSV scoring results and source snapshot are archived under legacy/ and cannot be selected by current scoring or report commands.

There is exactly one current recipe per dataset in results/gt_index.json. AIST++ TEST+VAL40 and FineDance loaderTEST19 are supplemental cohorts using the same respective scorers, not alternative protocol versions. Archived controls are excluded from current scoring and report inputs.

All commands hideCUDA, use at most2CPU threads, and constrain affinity to at most2currently permitted cores onLinux. Upstream sources are hash-pinned, untouched and fetched separately. Output directories are unique. Nonfinite values, missing members, unsupported timestamps, wrong hand provenance, changed hashes or absent real endpoints stop the pipeline. Do not drop cases, manufacture endpoints, substitute GT hands or change scorers to chase published values.

NativeGT, format/time controls, previousSMPL-X, SOMA roundtrip, tokenizer reconstruction and generation remain separate arms. No conversion or reconstruction is accepted merely because a scorer ran. Comparing a converted arm requires identical source, reference, time support, evaluator, assets,seed and repetitions. Physics/worldroot/latency metrics are additional and cannot be inferred from localBC/L1div.
